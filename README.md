# 💧 Water Level Indicator PCB

## Compact PCB Design for Water Level Monitoring

The Water Level Indicator PCB is a hardware project that monitors water levels in a storage tank and provides visual indication of the current level. The project focuses on designing a compact, reliable, and easy-to-fabricate PCB for practical water level monitoring applications.

---

## ✨ Features

* 💧 Water level monitoring
* 💡 LED-based level indication
* 📟 Compact PCB layout
* ⚡ Reliable electronic circuit design
* 🔌 Easy hardware integration
* 🛠️ Suitable for educational and prototype applications

---

## 🛠️ Tools & Technologies

* EasyEDA
* PCB Design
* Electronic Circuit Design
* Schematic Capture
* PCB Routing

---

## 🎯 Purpose of the Project

This project was created to learn the complete PCB design workflow—from schematic creation to PCB layout—while developing a simple and practical embedded hardware application.

Through this project, I gained experience in:

* Electronic circuit design
* PCB layout and routing
* Component placement
* Design Rule Check (DRC)
* Preparing designs for PCB fabrication

---

## 🚀 Project Workflow

1. Design the electronic schematic.
2. Select appropriate components.
3. Create the PCB layout.
4. Route signal traces and power connections.
5. Perform design validation.
6. Generate Gerber files for manufacturing.
